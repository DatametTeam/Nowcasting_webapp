# Weather Nowcasting Webapp v2

Modern web application for weather radar nowcasting visualization and analysis. Built with **FastAPI** (backend) + **Vue 3** (frontend), replacing the original Streamlit-based application.

## Architecture

```
nwc_webapp_v2/
├── backend/                    # FastAPI server (Python)
│   ├── main.py                # App entry point, router registration, SPA serving
│   ├── api/                   # API endpoint modules
│   │   ├── config.py          # /api/config/* — app config, model list, environment
│   │   ├── data.py            # /api/data/*   — SRI files, predictions, groundtruth
│   │   ├── jobs.py            # /api/jobs/*   — PBS job submission and monitoring
│   │   ├── rendering.py       # /api/render/* — overlay images, figures, GIFs
│   │   ├── metrics.py         # /api/metrics/* — CSI, POD, FAR, FSS, fit diagrams
│   │   └── realtime.py        # /api/realtime/* — start/stop/status real-time service
│   ├── services/              # Background services (real-time prediction loop)
│   ├── data/                  # Data utilities
│   ├── static/                # Built frontend assets (generated by `npm run build`)
│   └── requirements.txt       # Python dependencies
│
├── frontend/                   # Vue 3 + Vite SPA
│   ├── src/
│   │   ├── App.vue            # Root component with navigation bar
│   │   ├── router.js          # Client-side routing
│   │   ├── api.js             # Centralized API client (all backend calls)
│   │   ├── stores/            # Pinia state management
│   │   ├── views/             # Page-level components
│   │   │   ├── RealTimeView.vue        # Live radar map with animation timeline
│   │   │   ├── ModelComparisonView.vue # Side-by-side model predictions
│   │   │   └── MetricsView.vue         # CSI/POD/FAR/FSS/RMSE analysis + charts
│   │   └── components/        # Reusable UI components
│   │       ├── RadarMap.vue   # Leaflet map with overlay preloading
│   │       ├── ColorBar.vue   # Precipitation colorbar legend
│   │       ├── DataTable.vue  # Metric data table with color coding
│   │       ├── DateTimeInput.vue  # Date/time picker wrapper
│   │       ├── ModelSelector.vue  # Multi-model selection
│   │       ├── MetricSection.vue  # Collapsible metric section
│   │       └── StatusBadge.vue    # Status indicator badge
│   ├── package.json
│   └── vite.config.js         # Vite config with API proxy
│
└── README.md
```

## Prerequisites

- **Python 3.12** (via conda)
- **Node.js** (v20+ recommended)
- The `nwc_webapp` package installed (`pip install -e .` from the repo root)

### Conda Environment Setup

```bash
# The project uses a shared conda environment
eval "$(/path/to/miniconda3/bin/conda shell.bash hook)"
conda activate nwc_webapp
```

## Development

Development uses two servers running simultaneously: the Vite dev server (hot-reload for the frontend) and the FastAPI backend.

### 1. Start the backend

```bash
cd nwc_webapp_v2/backend
uvicorn main:app --port 8000 --reload
```

The backend automatically detects the environment:
- **HPC**: Uses real PBS job submission + radar data from `/davinci-1/`
- **Local**: Uses mock data generation for testing

API documentation is auto-generated at http://localhost:8000/docs

### 2. Start the frontend

```bash
cd nwc_webapp_v2/frontend
npm install       # first time only
npx vite --port 5173
```

Open http://localhost:5173 in your browser.

The Vite dev server proxies all `/api/*` requests to the FastAPI backend on port 8000 (configured in `vite.config.js`).

## Production Build

Build the frontend into static files that FastAPI serves directly:

```bash
cd nwc_webapp_v2/frontend
npm run build
```

This outputs optimized HTML/JS/CSS to `backend/static/`. Then only the backend server is needed:

```bash
cd nwc_webapp_v2/backend
uvicorn main:app --port 8000
```

FastAPI serves both the API and the SPA frontend from a single port.

## Pages

### Real Time (`/realtime`)
- Interactive Leaflet map with radar overlay
- 25-frame timeline: 13 past groundtruth frames (-60 to 0 min) + 12 future predictions (+5 to +60 min)
- Play/pause animation with speed control
- Start/pause backend prediction service
- Periodic groundtruth refresh (every 60s, even when paused)
- On start, instantly shows which models already have predictions

### Model Comparison (`/comparison`)
- Side-by-side groundtruth vs. model predictions for a selected timestamp
- CSI metrics per lead time and threshold
- Zoomable image viewer
- Download buttons for individual images or entire rows

### Metrics Analysis (`/metrics`)
- 6 tabs: **CSI**, **POD**, **FAR**, **FSS**, **RMSE**, **Fit Diagrams**
- Per-model data tables with color-coded cells
- Overall performance ranking tables
- Interactive Chart.js line charts (metric vs. lead time per threshold)
- Fit diagrams: server-rendered POD vs. FAR scatter plots with CSI contours
- Prediction availability checker with overwrite/compute-missing options
- Export to CSV and download charts as PNG
- Collapsible metric formulas reference section

## API Overview

| Endpoint Group      | Description                                     |
|---------------------|-------------------------------------------------|
| `GET /api/health`   | Health check                                    |
| `/api/config/*`     | App configuration, model list, environment info |
| `/api/data/*`       | SRI files, prediction/target data checks        |
| `/api/jobs/*`       | Submit PBS jobs, check status, error logs        |
| `/api/render/*`     | Overlay PNGs, figure PNGs, GIF files            |
| `/api/metrics/*`    | Compute metrics, comparison, fit diagrams       |
| `/api/realtime/*`   | Start/stop/status of real-time prediction loop  |

Full interactive docs: http://localhost:8000/docs
